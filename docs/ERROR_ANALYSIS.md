# Error analysis

Generated by `python -m hinglish.report` (also run by `scripts/evaluate_all_locked.sh`) from the
locked-test predictions of all four models.

Outputs:
- `artifacts/error_analysis/ERROR_ANALYSIS_REPORT.md` — summary tables (regenerated each run);
- `artifacts/error_analysis/error_summary.json` — per model: error rate, per-hint counts/error rates,
  confusion pairs (also served at `GET /api/v1/metrics/comparison` and shown in the Research section);
- `artifacts/error_analysis/errors_all_models.csv` — every misclassified test row per model
  (sample id, preprocessed text, gold, predicted, hint flags). Contains SentiMix text: do not publish.

## Method

Category flags are **heuristic hints** (regex/lexicon), not manual annotations, and do not explain
*why* a model erred:

| Hint | Rule |
|---|---|
| negation | `nahi, nahin, nhi, na, mat, never, not, no, don't…` (English ones were removed upstream, so this fires on Hindi negators) |
| contrast | `but, par, lekin, magar, phir bhi, however` (effectively `par`/`lekin`/`magar`) |
| emoji | Unicode emoji ranges |
| code-mixing | presence of common Romanized Hindi function words |
| short text | ≤ 4 tokens |

The original manual-annotation scaffold (`hinglish.error_analysis.build_error_analysis_scaffold`,
empty `annotation_*` columns) is unchanged and can be used for a human pass.

## Results (locked test, 1,457 tweets)

| Model | Error rate | Negation hint (n=387) | Contrast hint (n=62) | Emoji (n=279) | Code-mixing (n=736) | Short (n=33) |
|---|---:|---:|---:|---:|---:|---:|
| E1 | 50.2% | 56.1% | 54.8% | 53.0% | 50.8% | 48.5% |
| E2 | 45.0% | 48.1% | 41.9% | 47.7% | 45.7% | 42.4% |
| E3 | 35.3% | 40.6% | 35.5% | 34.1% | 38.7% | 27.3% |
| E4 | 32.2% | 35.7% | 29.0% | 32.6% | 35.1% | 27.3% |

Most frequent confusions: E1 positive→neutral (176); E2 positive→neutral (151); E3 neutral→negative
(139); E4 neutral→negative (125). Neutral is the hardest class for every model (test F1 45.7% /
49.4% / 56.6% / 58.9% for E1–E4).

## Observations (descriptive, not causal)

- Rows with a Hindi negator have a higher error rate than average for every model (e.g. E4 35.7% vs
  32.2% overall); E4's gap to E3 is largest on the contrast-hint subset (29.0% vs 35.5%), but n = 62
  is small, so this is suggestive only.
- Errors concentrate on the neutral boundary in both directions, consistent with the known label
  noise of SentiMix neutral.
- Because English `not`/`but` were stripped from the data upstream, sentences such as
  *"movie toh acchi thi but ending bakwas thi"* reach the models as `movi toh acchi thi end bakwa thi`;
  both E3 and E4 predict **neutral** for it in the live app. This is a data limitation, not something
  fixed by changing models.
