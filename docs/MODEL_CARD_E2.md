## Intended use

Research and teaching demonstration of sentence-level 3-class sentiment (negative / neutral / positive) for Romanized Hindi-English code-mixed social-media text, as part of the HinglishSense E1–E4 comparison.

## Out of scope

Decisions about individuals (moderation, hiring, credit, health, legal); measuring anyone's real feelings; Devanagari or non-Hinglish text; long documents; any use that treats the score as ground truth.

## Model

Word TF-IDF as E1 plus genuine character 3-grams (CharacterSplitter → NGram(3) → CountVectorizer(20,000) → IDF), concatenated by VectorAssembler, classified by OneVsRest(LinearSVC(maxIter=100)) because LinearSVC is binary-only in Spark MLlib.

Hyperparameters: `char_tfidf_num_features=20000`, `char_ngram_n=3`, `svc_reg_param=0.0`, `word_tfidf_num_features=20000`, `svc_max_iter=100`, `classifier=OneVsRest(LinearSVC)`, `smoke_test=False`

## Scores shown to users

Raw per-class SVM margins are not probabilities. A temperature softmax(m / T) fitted on the validation split maps them to calibrated class scores; it preserves the argmax, so the served class is always the native One-vs-Rest decision.

## Limitations and bias

- Linear model over n-grams: limited handling of long-range contrast.
- Character n-grams help with Romanized spelling variation but also pick up noise.
- English negators and contrast words (`not`, `no`, `but`) were removed from the data upstream, so no model can use them; Hindi ones (`nahi`, `mat`, `lekin`) remain.
- Tweets from one collection period; political and religious topics are heavily represented, and the neutral class is noisy. Errors are not uniform across topics.
- One split and one seed; no estimate of seed variance.
